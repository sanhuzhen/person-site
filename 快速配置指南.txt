Preason Vite - 快速配置指南
==========================

📁 配置文件位置：
   D:\vsProjects\preason-vite\config.json

🚀 如何使用：
   1. 打开 config.json 文件
   2. 修改你需要的内容
   3. 保存文件
   4. 运行 npm run dev
   5. 浏览器访问 http://localhost:5173

🎨 主要配置项：

   [个人资料]
   - avatar: 头像URL（留空显示默认占位符）
   - nickname: 昵称
   - description: 个人描述

   [列表内容]
   - skills: 技能列表
   - projects: 项目列表
   - interests: 兴趣列表

   [主题设置]
   - primaryColor: 主色调（按钮颜色）
   - backgroundColor: 背景色（已设为白色 #ffffff）
   - textColor: 文字颜色

💡 快速修改示例：

   修改昵称：
   "nickname": "张三"

   修改头像：
   "avatar": "https://example.com/photo.jpg"

   修改背景为白色：
   "backgroundColor": "#ffffff"

   添加技能：
   {
     "id": "1",
     "title": "React",
     "content": "前端框架",
     "icon": "⚛️"
   }

⚠️ 注意事项：
   - JSON格式要正确（逗号、引号）
   - ID要唯一
   - 修改后保存文件并刷新浏览器
